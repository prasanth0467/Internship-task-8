# Task 8: Simple Sales Dashboard Design

## Objective
Create a basic interactive dashboard to visualize sales performance by product category, region, and month.

## Tools Used
- Power BI

## Dataset
- Sample_Superstore.csv  
  Columns: Order Date, Region, Category, Sales, Profit

## Steps Followed
1. Imported the dataset into Power BI.
2. Converted 'Order Date' to 'Month-Year' format using a new calculated column.
3. Created the following visuals:
   - Line Chart: Sales over Month-Year
   - Bar Chart: Sales by Region
   - Donut Chart: Sales by Category
4. Added slicer for filtering by Region.
5. Applied color formatting to highlight top-performing regions and categories.
6. Exported the dashboard as a PDF/screenshot.

- `Insights.pdf` (slide)
- `Sample-Superstore.csv`(dataset)
